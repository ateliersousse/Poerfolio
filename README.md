# Portfolio — Achref Baklouti

Site statique responsive, prêt pour GitHub Pages. Aucun serveur ni installation requis.

## Publication sur GitHub Pages
1. Créez un dépôt GitHub public nommé `portfolio` (ou autre nom).
2. Importez **tous les fichiers et dossiers** de ce dossier à la racine du dépôt (index.html, style.css, script.js, assets/...).
3. Dans **Settings → Pages → Build and deployment**, choisissez **Deploy from a branch**, branche **main**, dossier **/(root)**, puis enregistrez.
4. Votre site sera disponible à l'adresse `https://VOTRE_IDENTIFIANT.github.io/portfolio/` après publication. Si le dépôt s'appelle `VOTRE_IDENTIFIANT.github.io`, l'adresse sera `https://VOTRE_IDENTIFIANT.github.io/`.

## Personnaliser les réalisations
Les sections Canva et Montage vidéo présentent actuellement des **couvertures graphiques de démonstration**, car les créations et vidéos originales n'ont pas été fournies. Ne les présentez pas comme des projets réels.

Pour ajouter vos créations :
- Placez les images dans `projects/designs/` et les vidéos ou miniatures dans `projects/videos/`.
- Modifiez la section `#projets` dans `index.html` pour remplacer les couvertures et les textes par vos vrais travaux, avec titres, descriptions et liens.
- Pour les vidéos lourdes, préférez des liens vers YouTube/Vimeo plutôt que de les stocker directement dans le dépôt.
